# שלח ללוח — תוסף פיגמה

תוסף קטן שלוקח את הצבעים של קובץ הפיגמה הפתוח ופותח איתם את עורך הלוח.
לחיצה אחת בפיגמה, והפלטה כבר בתצוגה המקדימה.

## למה תוסף ולא חיבור ישיר

ה‑REST API של המשתנים (Variables) בפיגמה זמין **רק בתוכנית Enterprise**.
התיעוד של פיגמה עצמה אומר שבכל תוכנית אחרת קוראים את המשתנים **מתוסף
צד‑לקוח** — וזה בדיוק מה שהתוסף הזה עושה. הוא רץ בתוך פיגמה, שם המשתנים
זמינים בכל תוכנית.

## התקנה (פעם אחת, דקה)

1. להוריד את התיקייה `figma-plugin/` מהפרויקט למחשב.
2. בפיגמה (אפליקציית הדסקטופ): תפריט → **Plugins** → **Development** →
   **Import plugin from manifest…** ולבחור את `manifest.json` שבתיקייה.
3. זהו. התוסף מופיע תחת Plugins → Development → "שלח ללוח - קרובים".

אין צורך בפרסום, בחשבון מפתחים או בתשלום.

## שימוש

1. לפתוח את קובץ הפיגמה שבו הצבעים.
2. Plugins → Development → **שלח ללוח - קרובים**.
3. בפעם הראשונה: להדביק את כתובת האתר (למשל `https://shul-hub.lovable.app`).
   היא נשמרת לפעמים הבאות.
4. **שלח ללוח** → נפתח הדפדפן על עורך הלוח, עם הפלטה כבר טעונה: רואים את כל
   הצבעים, את השיוך לתפקידים (רקע, טקסט, הדגשה…) ואפשר לשנות כל שיוך ולראות
   מיד. בסיום: **שמור ושדר**.

## מה נשלח, ולאן

רק שמות הצבעים והערכים שלהם, ורק של הקובץ הפתוח. הם נוסעים ב**חלק הפנימי של
הכתובת** (אחרי `#`) — דפדפנים לא שולחים את החלק הזה לשרת, ולכן הפלטה עוברת
מפיגמה לדפדפן שלך ולא לשום מקום אחר. אין טוקן, אין העלאה ואין שרת באמצע.

## מקורות בקובץ

- **משתני צבע** (Variables) — מועדף, כולל שמות עם היררכיה.
- **סגנונות צבע** (Paint Styles) — לקבצים שעדיין לא עברו למשתנים.

אם בקובץ אין אף אחד מהשניים, התוסף יאמר זאת.
