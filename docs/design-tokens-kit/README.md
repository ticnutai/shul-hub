# ערכת ערכות נושא וגרדיאנטים — להטמעה בפרויקט חדש

זו ערכה עצמאית להעתקה לכל פרויקט TypeScript. היא מוסיפה:

- **ערכות נושא** שהמשתמש יכול ליצור, לשמור, לערוך ולמחוק.
- **ספריית גרדיאנטים** עם אותן יכולות.
- **ייצוא וייבוא** בפורמט אחד, כך שאפשר להעביר ערכות וגרדיאנטים **בין תוכנות שונות**.

הקובץ `design-tokens.ts` שליד קובץ זה הוא המימוש המלא: בלי תלויות, בלי framework. המפרט המלא של הפורמט: [`../DESIGN_TOKENS_SPEC.md`](../DESIGN_TOKENS_SPEC.md).

### 1. העתיקו את `design-tokens.ts` לפרויקט

### 2. ערכו שני דברים בראש הקובץ

```ts
// אילו משתני CSS אצלכם ממלאים כל תפקיד
export const VAR_BY_ROLE = {
  background: "--my-bg",
  text: "--my-text",
  accent: "--my-brand",
  // תפקיד שאין לכם - פשוט השמיטו
};

// ערכת ברירת המחדל שלכם, מלאה ותקינה
export const DEFAULT_VARS = {
  "--my-bg": "#0b1628",
  "--my-text": "#f4f7fb",
  "--my-brand": "#f0c35c",
};
```

זה כל מה שצריך להתאים. כל השאר עובד כמו שהוא.

### 3. שמרו את הערכות והגרדיאנטים בהגדרות הקיימות שלכם

```ts
interface AppSettings {
  theme: string;          // מזהה הערכה הפעילה
  customThemes: Theme[];  // ערכות שהמשתמש יצר
  gradients: Gradient[];  // ספריית הגרדיאנטים
}
```

**לא** ליצור מנגנון אחסון נפרד. הן חלק מההגדרות, ולכן הן נהנות מהטיוטה, מהביטול ומהשמירה שכבר יש לכם.

### 4. החילו על הדף

```tsx
<div style={themeStyle(activeTheme)}>…</div>
```

## חמישה כללים שלא כדאי לשבור

**1. תפקידים, לא שמות משתנים.** ייצוא של `--my-brand` חסר משמעות בתוכנה אחרת; ייצוא של `accent` מובן בכל מקום.

**2. המזהים נוצרים ביבוא.** אף פעם לא לוקחים `id` מהקובץ — אחרת ייבוא פעמיים ידרוס את מה שכבר קיים.

**3. כלל ששומר גרדיאנט שומר את הערך עצמו.** לא הפניה לספרייה. כך מחיקת גרדיאנט מהספרייה לא שוברת אף מסך שמשתמש בו.

**4. אותה פונקציית אימות בשמירה וביבוא.** אם יש שתי דרכים להכניס נתונים, אחת מהן תהיה פחות בטוחה. הקובץ מגיע ממישהו אחר ונכנס לתוך `style` בדף.

**5. היבוא מוסיף ולעולם לא מוחק.** שם תפוס מקבל מספר. זה מה שמאפשר למשתמש לייבא בלי לחשוש.

## מה חייב להיות בממשק

| רכיב | דרישה |
|---|---|
| כרטיס ערכה | דוגמיות צבע אמיתיות, לא רק שם |
| שינוי צבע | מופיע **מיד** בתצוגה |
| שמירת ערכה | "שמירה כערכה חדשה" מהצבעים שעל המסך, ו"עדכון" לערכה שלי |
| מעבר בין ערכות | אם יש שינויים שלא נשמרו — **לשאול קודם** |
| בניית גרדיאנט | שני צבעים, ישר/מעגלי, וסרגל כיוון |
| גרדיאנט מתקדם | שדה CSS חופשי שנשמר **בדיוק** כפי שנכתב |
| הסרה | כפתור מפורש (`none`), לא רק "בחר משהו אחר" |
| תצוגה מקדימה | אף פעם לא נשמרת בשקט |

## בדיקות שכדאי להעתיק

1. **מחזור מלא:** ייצוא → ייבוא לאותה מערכת → שתי רשומות, השנייה עם `(2)`.
2. **קובץ ממערכת אחרת:** רק 3 תפקידים מוגדרים → ערכה שלמה ושמישה.
3. **גרסה עתידית:** `version: 99` → שגיאה ברורה.
4. **קובץ חלקי:** גרדיאנטים בלבד → עובד.
5. **הזרקות:** `url(...)`, `var(...)`, `;`, `}`, `image-set`, ערך ארוך מדי, `javascript:` → כולן נדחות.
6. **מחיקה מהספרייה:** מסך שמשתמש בגרדיאנט — לא משתנה.
