# תקן להעברת ערכות נושא וגרדיאנטים בין מערכות

**גרסה 1 · `design-tokens`**

מסמך זה מגדיר פורמט אחד להעברת **ערכות נושא** ו**גרדיאנטים** בין תוכנות שונות, ואת הכללים למימוש שלו. הוא נכתב כדי שתוכלו לממש את אותה מערכת גם בפרויקטים אחרים שלכם, ואז לייצא ערכה או גרדיאנט מתוכנה אחת ולייבא אותם לשנייה.

המימוש המלא שעובד כאן: `src/tv/transfer.ts` (הפורמט), `src/tv/themes.ts` (הערכות והאימות), `src/community/components/admin/tv/GradientStudio.tsx` (הממשק).

---

## 1. הרעיון המרכזי: תפקידים, לא משתנים

הטעות הטבעית היא לייצא את שמות המשתנים של התוכנה שלך (`--tv-accent`, `--brand-500`). קובץ כזה חסר משמעות בתוכנה אחרת.

לכן ערכת נושא מתוארת כאן ב**תפקידים** — מה הצבע *עושה*, לא איך הוא נקרא אצלך:

| תפקיד | מה זה | דוגמה |
|---|---|---|
| `background` | הרקע הראשי | `#0b1628` |
| `backgroundGlowTop` | גוון רקע משני (הילה עליונה / גרדיאנט) | `#1b3054` |
| `backgroundGlowBottom` | גוון רקע משני נוסף | `#16304f` |
| `surface` | רקע של כרטיסים ולוחות מעל הרקע | `rgba(255,255,255,0.05)` |
| `text` | צבע הטקסט הראשי | `#f4f7fb` |
| `textMuted` | טקסט משני | `#9fb2cc` |
| `accent` | צבע ההדגשה (כותרות, שעות) | `#f0c35c` |
| `accentAlt` | הדגשה משנית | `#b99236` |
| `onAccent` | טקסט שמופיע **על** צבע ההדגשה | `#0b1628` |
| `highlight` | הדגשה חריגה (נעוץ, התראה) | `#ef8f4c` |

כל תוכנה מחזיקה **טבלה אחת** שמתרגמת בין המשתנים שלה לתפקידים. זה כל מה שצריך להסכים עליו.

```ts
const VAR_BY_ROLE = {
  background: "--tv-bg-a",
  surface: "--tv-panel",
  text: "--tv-text",
  accent: "--tv-accent",
  // …
};
```

**גרדיאנט** פשוט יותר: שם + מחרוזת CSS. CSS הוא כבר השפה המשותפת.

## 2. מבנה הקובץ

```json
{
  "format": "design-tokens",
  "version": 1,
  "app": "shul-hub-tv",
  "exportedAt": "2026-09-20T12:00:00.000Z",
  "themes": [
    {
      "name": "חגים",
      "description": "על בסיס לילה כחול",
      "mode": "dark",
      "roles": {
        "background": "#101010",
        "backgroundGlowTop": "#202020",
        "backgroundGlowBottom": "#303030",
        "surface": "rgba(255, 255, 255, 0.05)",
        "text": "#ffffff",
        "textMuted": "#aaaaaa",
        "accent": "#ffcc00",
        "accentAlt": "#cc9900",
        "onAccent": "#101010",
        "highlight": "#ff8800"
      }
    }
  ],
  "gradients": [
    { "name": "ערב", "value": "linear-gradient(160deg, #0b1628, #1b3054)" }
  ]
}
```

**כללים:**

1. `format` חייב להיות `"design-tokens"`. זה מה שמבדיל בין הקובץ שלנו לכל JSON אחר.
2. `version` הוא מספר שלם. קובץ עם גרסה **גבוהה** מזו שהתוכנה מכירה — יש לסרב ולהסביר, לא לנחש.
3. `app` הוא לידיעה בלבד. **אסור** שתוכנה תתנה התנהגות בערך שלו.
4. `themes` ו-`gradients` שניהם אופציונליים. קובץ עם גרדיאנטים בלבד הוא קובץ תקין.
5. **אין מזהים (id) בקובץ.** מזהים הם עניין פנימי של כל תוכנה; היבוא מייצר חדשים. כך ייבוא פעמיים לעולם לא דורס.
6. `mode` הוא `"light"` או `"dark"` — כדי שהמייבא ידע לאיזו משפחה לשייך את הערכה.
7. תפקיד חסר הוא לגיטימי. המייבא משלים מברירת המחדל שלו.

## 3. אימות — הקובץ הוא קלט עוין

קובץ מגיע ממישהו אחר. הוא נכנס בסוף לתוך `style` בדף, ולכן:

**צבעים** — רק הצורות האלה:
```
#rgb · #rrggbb · #rrggbbaa · rgb(…) · rgba(…) · hsl(…) · hsla(…)
```

**גרדיאנטים** — רק פונקציות גרדיאנט, ורק תווים שאינם יכולים לפרוץ מההצהרה:
```ts
const OK = /^(repeating-)?(linear|radial|conic)-gradient\(/i;

export function isSafeGradient(v: string): boolean {
  const s = v.trim();
  if (s.length > 600 || !OK.test(s) || !s.endsWith(")")) return false;
  if (/[;{}\\<>]|url\(|var\(|expression|image-set|attr\(|@import/i.test(s)) return false;
  if (!/^[a-z0-9\s(),.%#-]+$/i.test(s)) return false;
  // הדפדפן עצמו הוא הבודק האחרון
  return typeof CSS !== "undefined" ? CSS.supports("background-image", s) : true;
}
```

מה שנחסם ולמה:
- `url(` — מונע בקשת רשת שמסגירה מי צופה במסך.
- `var(` — מונע שאיבת ערכים ממשתנים אחרים.
- `;` `{` `}` — מונע יציאה מההצהרה והזרקת כללים.
- אורך מוגבל — מונע קובץ שמנפח את מסד הנתונים.

**שמות** — חותכים לאורך סביר (40 תווים), ושם ריק נדחה.

**כלל עליון:** מייבאים דרך **אותה** פונקציית אימות שמשמשת את השמירה הרגילה. אם יש שתי דרכים להכניס נתונים, אחת מהן תהיה פחות בטוחה.

## 4. התנהגות היבוא

| מצב | ההתנהגות הנכונה |
|---|---|
| שם שכבר קיים | להוסיף עם סיומת: `"ערב" → "ערב (2)"`. לא לדרוס. |
| פריט לא תקין | לדלג עליו, **ולספור**. בסוף להודיע: "יובאו 3, דולגו 2". |
| הקובץ כולו לא תקין | שגיאה אחת ברורה בשפת המשתמש. |
| גרסה עתידית | לסרב במפורש. |
| ייבוא הצליח | להיכנס ל**טיוטה** — לא להחיל על המשתמשים לפני אישור מפורש. |

היבוא **תמיד מוסיף ולעולם לא מוחק**. זה מה שמאפשר לייבא בלי פחד.

## 5. ספריית הגרדיאנטים — כלל אחד קריטי

הספרייה היא רשימה של `{ id, name, value }`. הכלל החשוב:

> **כלל שמשתמש בגרדיאנט שומר את הערך עצמו, לא הפניה לספרייה.**

לכן מחיקת גרדיאנט מהספרייה לא משנה שום מסך שכבר משתמש בו. הספרייה היא מדף של דוגמאות, לא מקור אמת חי. זה גם מה שמאפשר לייצא ולייבא בלי לגרור תלויות.

שם שכבר קיים בספרייה **מעדכן** את הרשומה הקיימת (ושומר את ה-id שלה) במקום ליצור כפילות — ויש לומר זאת בממשק.

## 6. הממשק — מה חייב להיות

**לערכת נושא:**
- כרטיס לכל ערכה עם דוגמיות צבע אמיתיות, ולא רק שם.
- שינוי צבע מופיע **מיד** בתצוגה.
- "שמירה כערכה חדשה" מהצבעים שעל המסך, ו"עדכון הערכה" לערכה שלי.
- מעבר לערכה אחרת כששינויים לא נשמרו — **לשאול קודם**.

**לגרדיאנט:**
- שני צבעים, ישר/מעגלי, וסרגל כיוון. אלה מכסים את רוב הצרכים.
- דוגמית חיה גדולה מעל הבקרים.
- שדה CSS מתקדם למה שהבקרים לא מבטאים (שלוש שכבות, שקיפות, conic) — **והערך שנכתב שם נשמר בדיוק כפי שהוא**, בלי "ליישר" אותו לשני צבעים.
- כפתור הסרה מפורש (`none`).

**לשניהם:** תצוגה מקדימה אף פעם לא נשמרת בשקט. יש טיוטה, ויש פעולת שמירה מפורשת.

## 7. איך לממש את זה בפרויקט חדש — שישה צעדים

1. **הגדירו את התפקידים** אצלכם: טבלה אחת `role → CSS variable`. אם חסר לכם תפקיד, השאירו אותו ריק ביצוא.
2. **שימו את הערכות והגרדיאנטים בתוך מבנה ההגדרות הקיים** (`customThemes`, `gradients`) — לא במנגנון אחסון נפרד.
3. **כתבו פונקציית אימות אחת** לצבע ולגרדיאנט, והשתמשו בה גם בשמירה וגם ביבוא.
4. **ייצוא:** המירו לתפקידים, הוסיפו `format`/`version`/`exportedAt`, והורידו כקובץ (`Blob` + `URL.createObjectURL`). שום דבר לא צריך לצאת לשרת.
5. **יבוא:** בדקו `format`, בדקו `version`, מיינו מזהים חדשים, העבירו דרך האימות, ומזגו עם שינוי שם בהתנגשות.
6. **בדקו את המחזור המלא:** ייצוא → ייבוא לאותה מערכת → שתי רשומות ("ערב" ו"ערב (2)"), וייבוא של קובץ ממערכת אחרת.

### שלד מוכן להעתקה

```ts
export const FORMAT = "design-tokens";
export const VERSION = 1;

export function buildExport(themes: MyTheme[], gradients: MyGradient[]) {
  return {
    format: FORMAT,
    version: VERSION,
    app: "my-app",
    exportedAt: new Date().toISOString(),
    themes: themes.map((t) => ({
      name: t.name,
      mode: isLight(t.vars[VAR_BY_ROLE.background]) ? "light" : "dark",
      roles: Object.fromEntries(ROLES.map((r) => [r, t.vars[VAR_BY_ROLE[r]]])),
    })),
    gradients: gradients.map((g) => ({ name: g.name, value: g.value })),
  };
}

export function parseImport(text: string) {
  const raw = JSON.parse(text);               // טיפול בשגיאה בשפת המשתמש
  if (raw?.format !== FORMAT) throw new Error("לא קובץ עיצוב");
  if (raw.version > VERSION) throw new Error("גרסה חדשה יותר של הפורמט");

  const themes = (raw.themes ?? [])
    .map((t) => ({ id: newId(), name: clean(t.name), light: t.mode === "light", vars: fromRoles(t.roles) }))
    .filter(isValidTheme);                    // אותו אימות של השמירה
  const gradients = (raw.gradients ?? [])
    .filter((g) => isSafeGradient(g?.value) && clean(g?.name))
    .map((g) => ({ id: newId(), name: clean(g.name), value: g.value.trim() }));

  return { themes, gradients, skipped: (raw.themes?.length ?? 0) - themes.length };
}
```

## 8. הרחבות עתידיות — בלי לשבור

- **גופנים, רדיוס, צללים:** להוסיף כמפתחות אחים ל-`roles` (למשל `"typography"`), ולא בתוכו. תוכנה ישנה פשוט תתעלם מהם.
- **תפקיד חדש:** אפשר להוסיף בגרסה 1 עצמה — תפקיד שלא מוכר פשוט לא ממופה. רק **שינוי משמעות** של תפקיד קיים מחייב `version: 2`.
- **אוסף (pack) של כמה ערכות:** כבר נתמך — `themes` הוא מערך.
- **מבנה הלוח (`board`):** כבר נתמך, ראו סעיף 8.1.

### 8.1 מבנה הלוח: `board` ו-`layout`

עורך לוחות הברית (digital-prayer-canvas) כותב ליד `roles` של הערכה הראשונה גם את
**צורת הלוח**: `layout`, `header`, `appearance` ו-`content`. הייצוא כאן ב"הכל + מבנה הלוח"
כותב את אותו תיאור במפתח עליון `board`. הייבוא קורא את שני המקומות: קודם `board`,
ואחר כך את מה שליד הערכה הראשונה.

```json
"board": {
  "layout": { "tabletsGap": 6, "topOffset": 14, "tabletWidth": 40, "archRadius": 50, "archHeight": 34 },
  "header": { "shulName": "בית הכנסת אוהל יצחק" },
  "appearance": { "wallTexture": "jerusalem-stone", "rowSize": 1.9, "titleSize": 2.1 }
}
```

האחוזים הם של לוח ביחס 16:9. יחידת `--u` כאן היא אחוז מגובה הלוח, ולכן אחוז
אחד מהרוחב שווה 16/9 של `--u`. טבלת התרגום נמצאת ב-`src/tv/boardLayout.ts`:

| בקובץ | בלוח |
|---|---|
| `archRadius` ≥ 35 (לוחות מקושתים) | סגנון `tablets` (או `arch` על שיש) |
| `archRadius` נמוך יותר | מסגרת `round`, רדיוס ב-`--u` |
| `wallTexture` | סגנון: אבן → `stone`, שיש → `crown`, קטיפה → `velvet`, עץ → `wood` |
| `tabletsGap` | `spacing.gap` (יחסי) |
| `tabletWidth` (השוליים שנשארים בצדדים) | `spacing.sides` (יחסי) |
| `topOffset` | `spacing.top` (יחסי) |

**המרווחים יחסיים ולא מומרים אחד לאחד.** בעורך יש שני לוחות, וכאן שלוש עמודות, ולכן אותו
אחוז לא נותן אותו אוויר. ברירת המחדל של העורך (מרווח 6, רוחב 40, מלמעלה 14) משאירה את
המרווחים של הסגנון כמו שהם (`null`). שינוי בעורך מזיז את ברירת המחדל של הלוח באותו יחס:
חצי מרווח שם הוא חצי מרווח כאן. ברירות המחדל נמדדו בפריסת הלוח המלא עם הסגנון `tablets`
(מרווח 2u, צדדים 7u, מלמעלה 2.6u).
| `rowSize` | `textScale` (1.9 = 1) |
| `header.shulName` | `texts["header.title"]` |

**מה לא עובר:** השעון, עיטור הדפנה, עובי פס הזהב, המרווח בין שורות וצבעי הלוחות
עצמם. **זמני התפילות לא עוברים אף פעם**, כי הם נתונים שמגיעים מטבלת המניינים ולא עיצוב.
כל ערך נחתך לטווח המותר ועובר דרך `normalizeTvConfig`, כמו כל שמירה אחרת.

## 9. מה נבדק כאן

- מחזור מלא: ייצוא → ייבוא → `"ערב (2)"` בלי דריסה.
- קובץ ממערכת אחרת (שלושה תפקידים בלבד) — יובא והושלם לערכה מלאה.
- קובץ בגרסה 99 — נדחה בהודעה ברורה.
- קובץ בפורמט הישן — עדיין נקרא.
- קובץ אמיתי מעורך לוחות הברית (`design-tokens-kit/example-tablets-board.json`) — צבעים ומבנה, ומחזור מלא של המבנה (`src/tv/boardLayout.test.ts`).
- שבעה ניסיונות הזרקה (`url(`, `var(`, `;`, `}`, `image-set`, ערך ארוך מדי, `javascript:`) — כולם נדחו.
