# חיבור כלי עיצוב (MCP) — מה עוזר ומה לא

מסמך קצר: מה מחובר, איך משתמשים, ובעיקר — מתי זה באמת עוזר ומתי זה בזבוז.

## מה זה נותן

שרת MCP של כלי עיצוב מאפשר לסוכן (Claude) **לקרוא את העיצוב עצמו** — שכבות,
טקסטים, צבעים, משתנים (design tokens), מידות ומרווחים — במקום לנחש מצילום
מסך. זה מדויק: במקום "הכותרת נראית בערך 40 פיקסל", מתקבל
`font-size: 38, color: #1a2740, letter-spacing: -0.01em`.

**מה זה לא נותן:** אם העיצוב שרוצים לחקות הוא **תמונה** (JPG מאתר, צילום של
לוח מודפס) — MCP לא יעזור, כי אין שם קובץ עיצוב לקרוא. במקרה כזה העבודה היא
מה שנעשה בלוח הזה: לזהות את החומרים והצורות ולבנות אותם בקוד. MCP משתלם
כשהעיצוב **נולד** בפיגמה.

## מה מחובר

**המחבר הרשמי של Figma פעיל דרך חשבון Claude** — בלי טוקן, בלי `.mcp.json`
ובלי להתקין כלום. בדיקת `whoami` מחזירה את החשבון `ticnutai1`
(ticnutai@gmail.com), תוכנית starter, מושב View.

מה הוא יודע לעשות:

| יכולת | מה מקבלים |
| --- | --- |
| `get_metadata` | מבנה הקובץ: עמודים, שכבות, מיקומים וגדלים |
| `get_design_context` | ההקשר המלא של מסגרת או רכיב: טקסטים, צבעים, מידות |
| `get_variable_defs` | משתני העיצוב (design tokens) של הקובץ |
| `get_screenshot` | צילום של מסגרת |
| `download_assets` | ייצוא נכסים (SVG, PNG) מהקובץ |

### איך משתמשים

בפיגמה: לבחור מסגרת → קליק ימני → **Copy link to selection**, ולהדביק את
הקישור בצ׳אט יחד עם הבקשה. לדוגמה: "קח את המסך הזה ובנה ממנו ערכת נושא
ללוח". הקישור נראה כך, וזה כל מה שצריך:

```
https://www.figma.com/design/<fileKey>/<name>?node-id=1-2
```

מושב "View" בתוכנית החינמית מספיק לקריאה. אם קובץ מסוים לא ייפתח בגלל
הרשאות — החלופה למטה עובדת עם טוקן אישי.

### חלופה לטרמינל: Framelink (חינמי)

לאותה יכולת ב־`claude` בטרמינל (מחוץ לאפליקציה) אפשר להוסיף את Framelink.
הוא דורש טוקן אישי מפיגמה: Settings → Security → **Personal access tokens**
→ Generate (הרשאת קריאה מספיקה). הטוקן נשמר כמשתנה סביבה, לא בריפו:

```powershell
setx FIGMA_API_KEY "figd_..."
```

ואז קובץ `.mcp.json` בשורש הפרויקט:

```json
{
  "mcpServers": {
    "figma": {
      "command": "cmd",
      "args": ["/c", "npx", "-y", "figma-developer-mcp", "--stdio"],
      "env": { "FIGMA_API_KEY": "${FIGMA_API_KEY}" }
    }
  }
}
```

הקובץ הזה **לא** נמצא בפרויקט, כי המחבר הרשמי מייתר אותו.

## חלופה פתוחה לגמרי: Penpot

[Penpot](https://penpot.app) הוא פיגמה בקוד פתוח, אפשר להריץ על שרת משלך ויש
לו שרת MCP. מתאים אם לא רוצים תלות בחשבון פיגמה כלל. לא הוגדר כאן כי הוא
דורש התקנה משלו.

## מה כן עזר בפועל בלוח הזה

לא MCP, אלא:

- **מחולל חומרים** (`scripts/tv-textures.mjs`) — שיש, עץ, אבן וזהב מרעש
  פרקטלי, נאפים לתמונות. ראה [TV_DISPLAY.md](TV_DISPLAY.md).
- **מדידה במקום עין** — צילום הלוח ב-headless Chrome, בדיקת חיתוך שורות
  (`scrollHeight` מול `clientHeight`), ומדידת ראסטר עם CDP Tracing.
- **`corner-shape`** של CSS — צורת פינה אמיתית (רכה, קטומה, מגורעת) ולא רק
  רדיוס. נתמך ב-WebView של הקופסה (Chromium 152) ובכרום.
