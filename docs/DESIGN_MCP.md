# חיבור כלי עיצוב (MCP) — מה עוזר ומה לא

מסמך קצר: מה חיברנו, איך מפעילים, ובעיקר — מתי זה באמת עוזר ומתי זה בזבוז.

## מה זה נותן

שרת MCP של כלי עיצוב מאפשר לסוכן (Claude Code) **לקרוא את העיצוב עצמו** —
שכבות, טקסטים, צבעים, משתנים (design tokens), מידות ומרווחים — במקום לנחש
מצילום מסך. זה מדויק: במקום "הכותרת נראית בערך 40 פיקסל", הסוכן מקבל
`font-size: 38, color: #1a2740, letter-spacing: -0.01em`.

**מה זה לא נותן:** אם העיצוב שאתה רוצה לחקות הוא **תמונה** (JPG מאתר, צילום
של לוח מודפס) — שרת MCP לא יעזור, כי אין שם קובץ עיצוב לקרוא. במקרה כזה
העבודה היא מה שעשינו בלוח: לזהות את החומרים והצורות ולבנות אותם בקוד.
שרת MCP משתלם כשהעיצוב **נולד** בפיגמה או בפנפוט.

## מה מחובר בפרויקט

`.mcp.json` בשורש מגדיר שרת אחד, **חינמי**:

| שרת | עלות | מה הוא יודע |
| --- | --- | --- |
| **Framelink** (`figma-developer-mcp`) | חינם, קוד פתוח | לקרוא קובץ פיגמה: שכבות, טקסטים, צבעים, משתנים, ייצוא SVG |

שרת ה-Dev Mode הרשמי של פיגמה חזק יותר (Code Connect, כתיבה חזרה לקנבס) אבל
דורש מושב בתשלום, ולכן לא חובר.

## הפעלה (פעם אחת)

1. להוציא טוקן אישי מפיגמה: Settings → Security → **Personal access tokens** →
   Generate. הרשאת קריאה מספיקה. חשבון פיגמה חינמי מספיק לקבצים שלך.
2. להגדיר אותו כמשתנה סביבה בשם `FIGMA_API_KEY` (הטוקן **לא** נשמר בריפו —
   `.mcp.json` רק מפנה אליו):

   ```powershell
   setx FIGMA_API_KEY "figd_..."
   ```

3. לפתוח מחדש את Claude Code. אפשר לבדוק עם `/mcp` בטרמינל אינטראקטיבי.

בלי הטוקן השרת פשוט לא יעלה — שום דבר אחר בפרויקט לא נשבר.

## איך משתמשים

מעתיקים קישור למסגרת בפיגמה (Copy link to selection) ומבקשים, למשל:
"קח את המסך הזה ובנה ממנו ערכת נושא ללוח". הסוכן קורא את הצבעים והמידות
ויכול לייצא אותם דרך מערכת הייצוא/ייבוא הקיימת
([DESIGN_TOKENS_SPEC.md](DESIGN_TOKENS_SPEC.md)).

## חלופה פתוחה לגמרי: Penpot

[Penpot](https://penpot.app) הוא פיגמה בקוד פתוח, אפשר להריץ אותו על שרת משלך
ויש לו שרת MCP. מתאים אם לא רוצים תלות בחשבון פיגמה בכלל. לא הוגדר כאן כי הוא
דורש התקנה משלו; אם תרצה, מוסיפים אותו ל-`.mcp.json` באותה צורה.

## מה כן עזר בפועל בלוח הזה

לא MCP, אלא:

- **מחולל חומרים** (`scripts/tv-textures.mjs`) — שיש, עץ, אבן וזהב מרעש
  פרקטלי, נאפים לתמונות. ראה [TV_DISPLAY.md](TV_DISPLAY.md).
- **מדידה במקום עין** — צילום הלוח ב-headless Chrome, בדיקת חיתוך שורות
  (`scrollHeight` מול `clientHeight`), ומדידת ראסטר עם CDP Tracing.
- **`corner-shape`** של CSS — צורת פינה אמיתית (רכה, קטומה, מגורעת) ולא רק
  רדיוס. נתמך ב-WebView של הקופסה (Chromium 152) ובכרום.
